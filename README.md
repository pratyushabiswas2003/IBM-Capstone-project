# IBM Data Analyst Capstone Project

This repository contains my final project for the **IBM Data Analyst Professional Certificate**. It demonstrates a complete data-analysis workflow—from collecting and preparing data to exploring trends, creating visualizations, building dashboards, and communicating actionable insights.

## 📊 Project Overview

The project analyzes technology-related data from job postings, surveys, and other relevant sources to understand current and emerging skill requirements in the technology industry.

The analysis focuses on identifying trends in:

- Programming languages
- Databases
- Development tools and IDEs
- Other in-demand technology skills

The findings can help aspiring data professionals and technology organizations better understand which skills are most valuable in the job market.

## 🎯 Business Problem

Technology changes quickly, and the skills employers seek are constantly evolving. This project addresses the following question:

> **Which technical skills are currently in demand, and how are those requirements changing across the technology industry?**

By analyzing data from multiple sources, the project identifies patterns in employer requirements and presents the results in a clear, accessible format.

## 🔎 Analysis Workflow

### 1. Data Collection

Collected data from multiple sources using APIs, web scraping, and provided datasets. The collected information includes job-posting data, survey responses, and technology-related skill details.

### 2. Data Wrangling

Cleaned and prepared the data for analysis by:

- Handling missing values
- Removing duplicates
- Standardizing inconsistent formats
- Transforming columns into analysis-ready formats
- Validating data quality

### 3. Exploratory Data Analysis

Used statistical analysis and exploratory techniques to investigate distributions, relationships, patterns, and trends in the data.

### 4. Data Visualization

Created charts and visualizations to make the results easier to understand and highlight the most important findings.

### 5. Dashboard Development

Developed interactive dashboards to present key results and allow users to explore different aspects of the data.

### 6. Presentation of Findings

Summarized the analysis, explained the main insights, and discussed their implications for learners, job seekers, and organizations in the technology sector.

## 🛠️ Tools and Technologies
