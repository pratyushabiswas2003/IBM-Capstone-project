# IBM Data Analyst Capstone Project

This repository contains the final project completed as part of the IBM Data Analyst Professional Certificate. It demonstrates a complete data-analysis workflow, from data collection and preparation to exploratory analysis, visualization, and insight generation.

## 📊 Project Overview

The project analyzes technology-related data from job postings, surveys, and other relevant sources to understand current and emerging skill requirements in the technology industry.

The analysis focuses on identifying trends in:

- Programming languages
- Databases
- Development tools and IDEs
- In-demand technology skills

## 🎯 Business Problem

The goal of the project is to identify which technical skills are most in demand and how those requirements are changing over time across the technology sector.

By analyzing multiple data sources, the project uncovers patterns in employer requirements and presents the results in a clear and actionable format.

## 🔎 Analysis Workflow

### 1. Data Collection

Data was collected from multiple sources using APIs, web scraping, and provided datasets. The data includes job postings, survey information, and technology-related skill details.

### 2. Data Wrangling

The collected data was cleaned and prepared for analysis by:

- Handling missing values
- Removing duplicates
- Standardizing inconsistent formats
- Transforming columns into analysis-ready fields
- Validating data quality

### 3. Exploratory Data Analysis

Statistical analysis and exploratory techniques were used to investigate distributions, relationships, patterns, and trends within the data.

### 4. Data Visualization

Charts and visualizations were created to communicate important findings and make patterns easier to interpret.

### 5. Dashboard Development

Dashboards were developed to present key insights and allow different aspects of the data to be explored interactively.

### 6. Presentation of Findings

The final results were summarized to communicate the main insights and their business implications.

## 💡 Key Insights

The analysis highlights trends in the technology skills, programming languages, databases, and tools most frequently requested by employers.

- Programming languages with the strongest demand
- Databases and tools commonly required in job postings
- Emerging technology skills gaining importance in the market
- Patterns showing how skill demand shifts across the industry
